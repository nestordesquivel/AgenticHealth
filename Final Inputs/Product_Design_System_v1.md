# Product Design System
## Version 1.0

> **Purpose:** Single source of truth for designing and implementing Angy products.
>
> This document translates the Brand System into practical guidance for product design, frontend development, and AI-generated interfaces.
>
> It intentionally focuses on implementation rather than brand strategy.

---

# 1. Brand Essence

## Core Product Feeling

Every interaction with the product should make users feel:

- Calm
- Supported
- In control
- Confident
- Professionally assisted
- Less cognitively overloaded

The product should quietly reduce operational burden rather than demand attention.

## Product Personality

The product should feel:

- Professional
- Human
- Systematic
- Reliable
- Quietly confident
- Predictable

It should behave like a trusted operator working in the background.

## Never Feel Like

The product should never feel:

- Flashy
- Experimental
- Startup-like
- Futuristic
- Consumer wellness
- Playful
- AI-first

The technology should disappear behind the experience.

---

# 2. Design Philosophy

## Design Principles

- Clarity over cleverness.
- Reliability over novelty.
- Reduce cognitive load.
- Respect the user's attention.
- Simplicity before sophistication.
- Quiet confidence.
- Calm by default.

## Design Goals

Interfaces should be:

- Easy to understand
- Easy to scan
- Easy to trust
- Easy to operate

The UI should feel familiar rather than surprising.

---

# 3. Verbal Identity

## Voice

The product speaks:

- Calmly
- Clearly
- Professionally
- Warmly, but with restraint
- Confidently without sounding authoritative

## Writing Style

Prefer:

- Short sentences
- Operational language
- Outcome-first communication
- Direct instructions
- Plain language

## Avoid

Never use:

- Marketing language
- Buzzwords
- Hype
- Urgency
- Humor
- Emotional manipulation

Do not overemphasize AI.

AI is infrastructure, not identity.

## UI Copy

UI text should feel:

- Helpful
- Predictable
- Neutral
- Professional

Buttons and labels should prioritize clarity over creativity.

---

# 4. Visual Language

## Emotional Tone

- Calm
- Warm
- Professional
- Restrained
- Trustworthy

## Visual Density

- Low-density by default
- Medium density only when required

## Shape Language

- Mostly rectangular
- Subtle corner radius
- Soft geometry
- Minimal ornamentation

## Imagery

Prefer:

- Real people
- Real environments
- Authentic photography

Avoid:

- Futuristic AI imagery
- Abstract AI brains
- Neon effects
- Lifestyle clichés
- Hospital clichés
- Mascots

## Motion

- Minimal
- Functional
- Quiet
- Never decorative

# 5. Color System

| Role | Color | Hex |
|------|-------|------|
| Primary Brand | Deep Teal | `#2F6F6B` |
| Background | Warm Off White | `#F6F7F5` |
| Primary Text | Charcoal | `#2E2E2E` |
| Secondary Surface | Warm Light Gray | `#E6E8E4` |
| Warm Accent | Muted Sand | `#D6C7B2` |
| Success | Muted Green | `#5F8F6A` |
| Warning | Soft Amber | `#C9A24D` |
| Error | Muted Red | `#B25C5C` |

### Usage Principles

- Neutral colors dominate.
- Brand color is used intentionally.
- Functional colors communicate state.
- Color should never become decoration.

---

# 6. Typography

## Body

**Source Sans 3**

Weights:

- Regular
- Medium
- Semibold

## Headings

**Inter**

Weights:

- Medium
- Semibold
- Bold

## Reading Principles

- Comfortable line length
- Generous spacing
- Excellent readability
- No decorative typography

---

# 7. Layout Principles

- Strong visual hierarchy
- Large whitespace
- Low visual density
- Consistent spacing
- Typography before color
- Color before decoration
- Neutral surfaces dominate

---

# 8. Components

## Core Components

Future component library should standardize:

- Buttons
- Inputs
- Cards
- Navigation
- Forms
- Metric Cards
- Status Indicators
- Empty States
- Loading States

> Component specifications intentionally deferred.

---

# 9. Interaction

## Principles

- Fast
- Predictable
- Quiet
- Immediate feedback

## Motion

Animation should support orientation, never decoration.

---

# 10. Brand Guardrails

## DO

- Be calm.
- Be systematic.
- Be professional.
- Be restrained.
- Be human.
- Be reliable.
- Prefer clarity over cleverness.
- Prefer reliability over novelty.

## DON'T

- Use gradients.
- Use neon colors.
- Use futuristic AI aesthetics.
- Use glassmorphism.
- Use excessive shadows.
- Use decorative animations.
- Use playful illustrations.
- Use marketing language.
- Make AI the protagonist.

---

# Design North Star

> The best Angy interface is one that feels so calm, clear, and reliable that users stop noticing the software and simply focus on their work.
